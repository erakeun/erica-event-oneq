실제 양식으로 추후 교체 예정

이 문서는 학교 공식 문서·공식 의전 지침이 아닙니다. 실제 행사에 맞게 검토하고 수정해 주세요.
화면에서 편집한 식순이나 입력 내용이 반영된 파일이 아니라 기본 참고 예시입니다.

검토 전 참고 문구이며 최종 진행문이 아닙니다.
행사명·호칭·순서·시간을 실제 내용으로 바꾸고 행사 담당자의 확인을 받으세요.

1. 개회
진행 멘트 예시: “지금부터 협약식을 시작하겠습니다.”
현장 신호·준비 확인: 행사명·음향·시작 신호 확인

2. 참석자 소개
진행 멘트 예시: “오늘 함께해 주신 참석자를 소개하겠습니다.”
현장 신호·준비 확인: 호칭과 소개 순서 사전 확인

3. 양측 인사말
진행 멘트 예시: “이어서 사전에 정한 순서에 따라 인사 말씀을 듣겠습니다.”
현장 신호·준비 확인: 발언자·발언 순서·마이크 확인

4. 협약서 서명
진행 멘트 예시: “다음은 협약서 서명 순서입니다. 서명자께서는 준비된 자리로 이동해 주시기 바랍니다.”
현장 신호·준비 확인: 서명자 확인 / 최종 협약서와 서명 위치 확인 / 펜 준비 / 서류 배치 담당 확인

5. 교환·기념촬영
진행 멘트 예시: “협약서를 교환한 뒤 기념촬영을 진행하겠습니다.”
현장 신호·준비 확인: 교환 방법·촬영 위치·서류 방향 확인

6. 폐회
진행 멘트 예시: “이상으로 협약식을 마치겠습니다. 함께해 주셔서 감사합니다.”
현장 신호·준비 확인: 후속 일정·퇴장 동선 확인

예정과 달라지면 확인되지 않은 내용을 즉흥적으로 안내하지 말고 담당자와 진행 순서를 확인하세요.
