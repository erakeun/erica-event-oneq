# 문서 자료

현재 12개 TXT는 모두 **V0.2 프로토타입용 임시 샘플**이며 **실제 양식으로 추후 교체 예정**입니다.

- 행사별 식순 5개와 사회자 시나리오 5개
- 협약서 구성 예시 1개(서명용 계약서 아님)
- 환영사 작성 예시 1개

학교 공식 양식이나 확정된 진행문이 아닙니다. 파일에 개인정보를 넣지 않았습니다.
실제 파일은 이 폴더에 넣고 루트 `data.js`의 `TEMPLATES`에서 `path`, `format`, `status`를 교체하세요. UI를 바꿀 필요는 없습니다. 자세한 방법은 루트 README에 있습니다.
