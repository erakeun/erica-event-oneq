# V0.4 검증 · 2026-09-22

기준 main: `1e13052` (V0.3.2). 기존 정적 구조와 V0.3 기능을 유지했다. 수정 저장소는 erica-event-oneq 하나다. 모든 브라우저 조작은 Codex 자체 브라우저에서 가상 선택/역할/메모로 수행했다.

## 자료 확인과 원본 보존

- 사용자 제공 협약식·기금전달식 PDF는 각 4쪽. 본문 텍스트 추출 및 식순/설명/참석자 표 렌더를 확인했다. 자료의 인명·기관명·금액은 이미 치환형이었다.
- HWP 본문은 OLE 스트림을 읽고 압축된 BodyText를 해제해 PDF와 대조했다. HWP에 편집·재저장·변환을 하지 않았다.
- `agenda-mou.hwp`: 198144 bytes, SHA-256 `2d9cc6fde5aca760782132d3649cd844944c3963e5a4733f0fed6eccc0f2d226`.
- `agenda-donation.hwp`: 320000 bytes, SHA-256 `d391857ee16550d4dc228b3eb2b2e0c61cb940f24a7ec484c8c6b896682a4e13`.
- 실제 PDF/HWP 식순은 사용자 지시의 8개 순서와 일치했다. 협약식의 별도 특정 기관 진행 시나리오 원본은 이번 4개 파일에 없어서, 지시문에 명시된 구조를 바탕으로 치환형 참고 원고를 작성했다.
- 참고 PDF와 추출 텍스트·메타데이터 검사 산출물은 공개 저장소에 넣지 않는다.

## 변경 전 UX 감사

Codex 브라우저에서 협약식/기금전달식을 각각 장소→행사정보→요청→식순→좌석→화면→준비표→현장점검→역할표→사후정리로 조작했다.

- 식순은 포함/순서 이동만 가능하여 명칭 수정·추가·삭제가 불가능했다.
- 식순 카드마다 멘트가 흩어져 있었고 전체 시나리오 복사가 없었다.
- 실제 HWP 없이 모든 자료가 임시 TXT였으며 자료 영역은 긴 식순 뒤에 있었다.
- 주차 안내 메모는 있었지만 등록 여부를 따로 확인할 수 없었다.
- 대관/세팅 전화가 미등록이었다.
- 캠퍼스, 안내문, 다과/식사, 역할/현장점검, 사후정리는 이미 작동하므로 유지했다.

## 자율 UX 개선

- 원본 HWP를 식순 화면 상단에 배치하고 작성 참고 자료는 접었다. 다운로드와 화면 편집의 차이를 명시했다.
- 식순과 시나리오를 별도 영역으로 나누고 맨 위에 보기/복사를 배치했다.
- 기존 저장 식순을 조용히 새 추천으로 덮어쓰지 않고 명시적으로 복원하도록 안내했다.
- 항목별 편집 펼침 상태를 고유 ID로 유지해 한 항목을 열어도 다른 항목이 모두 펼쳐지지 않게 했다.
- 항목 추가 시 이름 입력에 포커스를 두고, 삭제에는 확인/취소를 제공했다. 방향키가 아닌 위/아래 버튼을 키보드 Enter로도 실행할 수 있다.
- 개회 원고의 전체 순서를 현재 편집한 식순으로 연결했다.
- 편집/복사/인쇄/준비표/현장 식순은 같은 데이터 해석 함수를 사용한다. 다운로드 완료를 준비 완료로 바꾸지 않는다.
- 주차등록 상태를 준비표와 질문 화면 사이에서 일치시킨다. 실제 현장 확인은 자동 완료하지 않는다.
- 긴 원고가 각 체크의 변경 감지 정보에 중복 저장되지 않게 하여 50개 긴 식순도 저장 공간을 관리한다.

## 한계와 공개 배포 승인

- 인쇄 버튼과 인쇄 CSS를 확인했다. OS 인쇄 미리보기는 Codex 브라우저에서 접근할 수 없어서 실제 페이지 나눔/프린터 출력은 미검증이다. 이전 V0.3의 인쇄 PDF 검증을 이번 버전의 검증으로 간주하지 않는다.
- 실제 한글 앱에서 HWP를 열고 편집하는 검증은 하지 않았다. 원본과 바이트가 같으며 다운로드되는 것을 검증했다.
- 사용자가 두 HWP의 작성자·저장 사용자 메타데이터를 포함한 원본의 Public GitHub 및 GitHub Pages 공개를 명시적으로 승인했다. 메타데이터 제거·수정·재저장 없이 원본을 배포한다.
- 따라서 이 기록 시점에는 **로컬 검증 완료 / 원본 공개 승인 완료**다. GitHub Pages HTTP 200과 공개 파일 해시 검증은 배포 단계에서 별도로 수행해야 한다.
- 기존 제작기·실제 접수 시스템은 변경하거나 제출하지 않았다. 이번 요구의 연락처 외 담당부서·외선·시설 규칙·주차 시스템은 추가하지 않았다.
