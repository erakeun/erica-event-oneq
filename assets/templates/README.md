# 행사 참고 자료

- `agenda-mou.hwp`, `agenda-donation.hwp`: 사용자 제공 식순지 원본. 바이너리를 수정하지 않았다. 원본 해시는 `tests/agenda.test.mjs`에서 확인한다. 사용자가 작성자·저장 사용자 메타데이터를 포함한 원본의 Public GitHub 및 GitHub Pages 공개를 명시적으로 승인했다.
- 두 행사의 TXT 식순은 간단한 기본 구조 참고본이며 HWP 다운로드를 대체하지 않는다.
- 사회자 TXT는 화면 편집 전 기본 참고 원고다. 현재 편집한 원고는 화면의 시나리오 복사/인쇄를 사용한다.
- 그 밖의 TXT는 임시 샘플이다. 학교 공식 양식이나 확정 원고가 아니다.

파일 교체 시 `data.js`의 `TEMPLATES`에서 `path`, `format`, `status`를 바꾼다. `real`은 실제 제공 파일을 뜻하며 학교 공식 승인이나 최종 원고임을 보증하지 않는다.
