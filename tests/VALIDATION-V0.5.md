# V0.5 검증 · 2026-09-22

기준 main: `ac5e94c` (V0.4). erica-event-oneq만 수정했다. 기존 7단계, 정적 GitHub Pages, HWP 원본과 저장키를 유지한다. 모든 명단·역할·메모는 가상 데이터로 검증했다.

## 사용 흐름

행사 정보 → 참석자 명단 관리 → 식순 편집 → 진행 큐시트 → 행사 운영본 → 행사 당일 모드. 저장·복원 화면에서 전체 JSON 보관/복원과 지난 행사 복제를 제공한다. 모든 입력은 localStorage와 로컬 파일만 사용하며 서버로 전송하지 않는다.

- 참석자: 기관/구분·소속·직책·성명·비고, 추가/수정/확인 후 삭제/위아래 이동, 입력 인원과 기관별 인원, 현장 도착 확인. 최대 300명.
- CSV: UTF-8 BOM, 인용부호·쉼표·개행, 빈 행 무시, 성명 필수, 길이/열 수/300명/1MB 제한, 예상 밖 컬럼은 제외 사실을 미리보기에서 공개. 추가/전체 교체 구분, 교체 확인. 수식 시작 문자와 선행 공백·제어문자에 CSV Injection 방어.
- 큐시트: 최대 150행, HH:MM 또는 미정, 담당·행동·비고, 행 추가/수정/확인 후 삭제/위아래 이동. 식순 초안 생성은 확인 후 제목만 가져오며 시간·담당·행동은 비운다. 시간 역전은 순서를 유지하고 경고한다.
- 운영본: 기본정보/확인된 연락처/명단/역할/식순/큐시트/준비물/외부인·주차/다과/촬영·홍보/현장/사후를 조건에 맞춰 표시. 비어 있거나 불필요한 섹션은 제외한다.
- 당일 모드: 식순·시나리오/큐시트/명단과 도착 확인/역할표/현장점검에 빠르게 접근. 긴 명단에서도 이동 버튼이 상단에 유지된다.
- JSON: schemaVersion 5, 3MB 제한, 타입/버전/길이/ID/위험 키/깊이 검증. 실패·취소 시 현재 행사를 유지하고 교체 전에 확인한다. 객체 키 순서가 달라도 정상 자료를 읽는다.
- 복제: 구조는 유지하고 날짜·전체 완료 상태·주차·도착 확인·담당 배정·큐시트 시간·사후 메모를 비운다. 참석자 유지/비우기 선택. 기존 행사는 자동 보관하지 않음을 설명하고 JSON 선저장을 안내한다.
- 변경 재확인: 참석자 변경은 소개/명패/좌석/주차/다과 인원/단체촬영/운영본만 재확인한다. 무관한 화면·장소 완료는 보존한다. 큐시트와 작성 파일을 자동 삭제하지 않는다. 일시·장소 변경 시 관련 현장 확인과 도착 확인을 초기화한다.

## 기존 도구 READ ONLY 확인

2026-09-22 공개 HTML/스크립트를 읽어 실제 수신 형식을 확인했다. 다른 저장소와 도구의 저장 데이터는 수정하지 않았다.

- https://erakeun.github.io/nameplate-maker/ : CSV/TSV 파일의 첫 세 열을 이름·소속·직책으로 읽는 위치 기반 파서다. 머리글을 건너뛰지 않으므로 **명패용 CSV는 머리글 없이** 내보내며 줄바꿈은 공백으로 바꾼다. 기존 postMessage 경로는 좌석 도구 전용이므로 원큐에서 이를 흉내 내지 않는다.
- https://erakeun.github.io/erica-seat-planner/ : CSV 이름/성명, 소속, 직위/직책, 기관, 비고 별칭을 확인했다.
- https://erakeun.github.io/seoul-seat-planner/ : 동일한 참석자 CSV 컬럼 별칭을 확인했다.
- 사용자가 파일을 내려받고 각 도구에서 직접 가져오도록 안내한다. 기관별 순위·고정석·의전 역할은 생성하지 않는다. 외부 도구에 실제 명단을 넣거나 자동 전송하지 않았다.

## 반응형·시각 감사

4개 행사 × 1440/390/412px × 7단계+7개 운영 화면+6개 당일 화면 = **240개 화면**. 가로 넘침과 화면 밖 입력/버튼 없음 (`layout-v0.5.json`).

시각 검사에서 모바일 표 caption이 좁아 세로로 줄바꿈되는 문제를 발견해 수정했다. 긴 명단에서도 당일 이동 메뉴를 상단 고정했다. 수정 후 12개 관련 화면을 다시 확인했고 표 제목 폭 316px 이상, 메뉴 상단 위치 0px, 넘침 없음을 확인했다 (`layout-v0.5-final.json`). 데스크톱 운영본 및 390px 당일 화면 스크린샷을 확인했다.

## 인쇄 및 한계

운영본 인쇄 버튼을 실제 실행했다. A4/15mm, 네비게이션과 버튼 숨김, 반복 표 머리글, 행 내부 분할 방지, 반응형 표 규칙을 screen 매체로 한정한 CSS를 검토했다. Codex 자체 브라우저에서는 OS 인쇄 미리보기/실물 프린터 출력에 접근할 수 없어 실제 페이지 나눔은 미검증이다. 실제 한글 앱에서 HWP를 편집하는 검증도 수행하지 않았다.

개발 시점의 공개 배포 전 기록이다. 병합 후 Pages 배포 상태와 공개 파일의 HTTP 200/원본 해시, 운영 사이트 핵심 흐름을 별도로 검증한다.
