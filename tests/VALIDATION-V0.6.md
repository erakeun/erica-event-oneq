## 인쇄와 범위

- 실제 Chrome PDF를 PNG로 렌더링하여 첫 장과 마지막 장의 텍스트/표/페이지 경계, 반복 열 제목, 버튼/네비 숨김을 확인했습니다.
- 26개 업무 샘플: 전체 3쪽, 사람별 6쪽(5명 각 1쪽 + 미배정 1쪽), 시간순 2쪽. 분량이 많은 사람은 여러 쪽으로 이어집니다.
- 드래그앤드롭 대신 PC/모바일 공통 드롭다운 배정을 제공합니다.
- 같은 행사일의 시간 구간만 비교하며 자정 횡단 업무는 분할 입력합니다. 미정/역전 시간은 충돌 판정 대신 안내합니다.
- 브라우저 로컬 저장이며 자동 기기간 동기화는 없습니다. 실제 프린터와 iOS Safari는 별도 확인 범위입니다.

## 재현

```sh
npm test
python3 -m http.server 4186 --bind 127.0.0.1
# 별도 터미널: Playwright와 Chrome이 있는 환경
ONEQ_URL=http://127.0.0.1:4186/ \
PLAYWRIGHT_PATH=/absolute/path/to/node_modules/playwright \
EVIDENCE_DIR=/absolute/path/to/evidence \
node tests/browser-assignments.mjs
```

배포 후 같은 브라우저 시나리오를 공개 URL에서 다시 실행합니다. 검증 데이터는 별도 브라우저 컨텍스트의 로컬 저장소만 사용합니다.
