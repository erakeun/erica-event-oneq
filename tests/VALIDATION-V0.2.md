# V0.2 UX 감사와 검증

날짜: 2026-09-21. macOS, Node 22.23.2, Python 3.9.6, Codex 내장 브라우저. 가상 선택만 사용. 기존 MACH·제작기에는 읽기 전용으로만 접근했으며 접수·개인정보 입력은 하지 않음.

## 수정 전 실제 사용에서 확인한 점

V0.1 로컬 실행본의 장소→행사 정보→요청→식순→좌석→화면→준비표를 조작했다. A의 프라임/MOU/참석, C의 부서/시상식, D의 미정/기금전달식을 확인했다. B는 서울 장소가 없어 기타 장소/미팅으로 기존 안내를 점검했다.

- 서울 회의실 선택과 전용 연결이 없음.
- 홍보 불필요 회의도 보도자료 제출 항목을 제거할 수 없음. 주요 보직자 미참석이면 모든 행사에 자체 촬영 항목이 생김.
- 프라임 좌석 도구가 필요 여부와 무관하게 표시됨. 명패를 아직 결정하지 않아도 제작기 링크가 노출됨.
- 모든 양식이 HWP 준비 중으로 실제 다운로드 불가.
- 촬영 요청이 보도자료 카드 뒤에 있어 우선 확인할 일로 잘 드러나지 않음.
- 모바일 화면·안내물 생략 버튼이 모든 도구 카드 아래에 있어 긴 스크롤이 필요함.
- 다음 버튼은 다음 단계의 내용을 알 수 없고, 준비표 수정 버튼은 장소 단계로만 돌아감.
- 화면 넘침은 기존 390px에서도 없었고, 행사별 역할·준비물·멘트는 이미 적절한 예시이므로 유지함.

## 요구사항에 따른 변경

서울 장소의 확인된 49+4석과 기존 전용 링크를 VENUES 설정에 추가. 필요한 경우에만 좌석·명패·결과물 도구 연결. VIP 조건과 독립적인 보도자료 선택 및 눈에 띄는 촬영 요청. 행사별 식순·사회자·협약서·환영사 TXT 12개를 실제 제공. 샘플과 공식 문서의 차이를 명시. 자료 레지스트리와 형식 검증을 분리.

## 실제 사용을 근거로 자율 개선한 점

1. 필요 없는 홍보·좌석·명패 작업을 제외하고 미정은 별도 결정 항목으로 남김. 회의에 일률적으로 붙던 자체 촬영 체크 제거(촬영 식순이 있는 행사는 그 순서의 준비물 안내 유지).
2. 화면·안내물의 필요 없음/나중에 버튼을 상단으로 이동. 선택한 결과물만 제작기 버튼 노출.
3. 다음 버튼에 단계 이름 표시. 의미가 중복되던 일반 ‘나중에’ 버튼은 없애고, 미정 상태 그대로 다음으로 갈 수 있게 유지.
4. 브라우저 뒤로/앞으로 이동 지원. 준비표 그룹마다 해당 단계로 돌아가는 수정 버튼 제공.
5. 선택한 식순을 준비표에서 항상 볼 수 있게 하고 인쇄에도 포함.
6. V0.1 저장 내용 마이그레이션. 브라우저 검증 중 오래된 JS가 남는 것을 발견해 V0.2 자산 버전 쿼리 추가.

## 자동 검증

`npm test`: 25개 통과. 원본 출력 `test-output-v0.2.txt`.

- 기존 회귀: 체크 무효화·유령 항목 제거·선택 보존·저장 차단·손상 JSON·초기화 격리·입력 검증·안전한 다운로드 경로.
- 신규: 서울/프라임 링크 분리, 좌석/명패/홍보 선택 독립성, 필요 없음→다시 필요 시 완료 부활 금지, V0.1 마이그레이션, 실제 12개 파일/샘플 표시/필터.
- 5행사 × 6장소 × 3참석 × 3좌석 × 3홍보 × 3명패 = 2,430개 조합에서 상태 복원·조건별 항목·고유 ID 확인.

추가 실제 조작:

- 전달식 촬영 식순 제외·전달 순서 이동 → 준비표 반영.
- 체크를 직접 완료로 변경 → 새로고침 후 보존. 브라우저 뒤로/앞으로로 준비표↔화면 단계 복귀.
- 초기화 취소 시 보존, 확인 시 기본값으로 복원. 방향키로 라디오 이동과 포커스 유지.
- TXT 다운로드 클릭의 실제 download 이벤트 확인. 12개 TXT 모두 실제 HTTP 200 및 필수 두 문구 확인.
- 촬영 링크 클릭 후 원큐 요청 체크가 여전히 할 일인 것 확인.
- 인쇄 버튼 실행. 앱 JavaScript 오류/경고 로그 없음.
- 외부 연결 10개 HTTP 200 (`links-v0.2.json`). Seoul 운영 HTML의 명칭과 49+4=53석 읽기 전용 대조.

## 한계

- 실제 HWP 미제공. 현재는 TXT 샘플 다운로드를 검증했고, 향후 HWP 원본 앱 호환성은 등록 시 확인해야 함.
- 인쇄용 상태 텍스트·선택 식순·버튼 숨김·행 분할 방지 CSS를 검토. 내장 브라우저가 OS 인쇄 미리보기를 노출하지 않아 **실제 페이지 나눔·프린터 출력은 미검증**.
- 촬영 링크는 `erica-press`에서 Google Apps Script로 이동. 자동 승인 검토가 비공개 Google 콘텐츠 접근 가능성을 이유로 목적지 DOM 읽기를 차단함. 우회하지 않았으며 **목적지 화면 내부는 미검증**. 링크 열기와 HTTP 응답까지만 확인. 실제 접수·지원 확정은 테스트하지 않음.
- 대관 연락처·절차·장비 대응은 미확인 표시 유지. 실제 내부 지침을 창작하지 않음.

V0.1의 `VALIDATION.md`와 기존 스크린샷/출력은 당시 기록으로 보존했다. 본 문서와 `v0.2` 파일들이 현재 버전의 검증 기록이다.
